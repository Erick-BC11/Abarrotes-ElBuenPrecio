# Abarrotes-ElBuenPrecio
Creadores: Brandon Isaac Miranda Montes, Juraz Gael Miranda Coronado y Erick Bustamante Cruz


Este fue uno de los primeros trabajos de diseños de interfaz que nos dejó hacer el maestro Álvaro. Primero consistió en nosotros identificar los requerimientos funcionales y no funcionales que fueran a ocupar un sistema de abarrotes. Conforme a lo que identificamos, nos pidió realizar un diseño de interfaz que cumplieran con los requerimientos que habíamos escrito. 


![Captura 1](Captura%20de%20pantalla%202026-09-28%20184129.png)
Muestra la pantalla de Inicio de sesión. Se observa el diseño estándar para ingresar credenciales y un estado de error que resalta en rojo cuando el "Usuario o contraseña incorrecta

![Captura 2](Captura%20de%20pantalla%202026-09-28%20184642.png)
Muestra la pantalla de bienvenida para el Administrador (con el menú lateral colapsado y expandido) y la vista principal del módulo de Inventario. En el inventario se lista la tabla de productos y se muestra el funcionamiento de la barra de búsqueda

![Captura 3](Captura%20de%20pantalla%202026-09-28%20184659.png)
Muestra interacciones y estados vacíos dentro del Inventario. Incluye una búsqueda sin resultados ("No se encontraron productos"), un mensaje de advertencia por no seleccionar un producto antes de una acción, la selección de un producto mediante una casilla, y los campos en blanco para insertar un nuevo artículo

![Captura 4](Captura%20de%20pantalla%202026-09-28%20184712.png)
Ilustra el flujo para eliminar un producto en el inventario. Muestra desde la advertencia de no haber seleccionado nada, la selección del producto, hasta la ventana emergente de confirmación que pregunta "¿Seguro que quieres eliminar lo seleccionado?"

![Captura 5](Captura%20de%20pantalla%202026-09-28%20184723.png)
Es la conclusión del flujo de eliminación. Muestra el mensaje de éxito "¡Se ha eliminado exitosamente!" y cómo la tabla del inventario se actualiza removiendo el producto eliminado

![Captura 6](Captura%20de%20pantalla%202026-09-28%20184753.png)
Muestra los módulos de Cobro en caja y Devoluciones para el Administrador. Detalla el proceso de venta (selección de método de pago, procesamiento de tarjeta, pago aprobado/rechazado por fondos insuficientes) y el proceso para registrar devoluciones buscando por número de folio

![Captura 7](Captura%20de%20pantalla%202026-09-28%20184813.png)
Continúa con el módulo de Cobro en caja, enfocándose en el manejo de errores y cancelaciones. Muestra alertas cuando un código de barras no existe, errores al intentar cancelar un producto que no está en la compra actual, y la confirmación para cancelar una compra completa

![Captura 8](Captura%20de%20pantalla%202026-09-28%20184912.png)
Explora el resto de los módulos exclusivos del Administrador. Incluye la gestión de Proveedores (vistas de lista y detalles), Reportes de Ventas (con gráficas anuales y mensuales), gestión de Usuarios (creación, información y eliminación), y el sistema de Respaldos (configuración de copias de seguridad manuales/automáticas y errores de espacio en disco)

![Captura 9](Captura%20de%20pantalla%202026-09-28%20184925.png)
Muestra las interfaces desde el rol del Cajero. Incluye su propia pantalla de bienvenida y acceso a los módulos operativos esenciales: Cobro en caja (procesamiento de pagos y errores), Devoluciones e Inventario, limitando visualmente las opciones administrativas
