# Abarrotes-ElBuenPrecio
Creadores: Brandon Isaac Miranda Montes, Juraz Gael Miranda Coronado y Erick Bustamante Cruz


Este fue uno de los primeros trabajos de diseños de interfaz que nos dejó hacer el maestro Álvaro. Primero consistió en nosotros identificar los requerimientos funcionales y no funcionales que fueran a ocupar un sistema de abarrotes. Conforme a lo que identificamos, nos pidió realizar un diseño de interfaz que cumplieran con los requerimientos que habíamos escrito.
